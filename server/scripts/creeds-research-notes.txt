CONFESSION_FIELDS:
  Top level: Metadata, Data
  Metadata: Title, Year, CreedFormat, SourceAttribution (and others: Authors, AlternativeTitles, Location, OriginStory, OriginalLanguage, SourceUrl)
  Data: array of chapters
  Chapter: { Chapter (int), Title (str), Sections (array) }
  Section: { Section (int), Content (str), ContentWithProofs (str), Proofs (array) }
  Proof: { Id (int), References (array of str) }

CATECHISM_FIELDS:
  Top level: Metadata, Data
  Metadata: Title, Year, CreedFormat, SourceAttribution
  Data: array of questions
  Question: { Number (int), Question (str), Answer (str) }
  NOTE: Some catechisms have AnswerWithProofs and Proofs fields (WLC has them; WSC does NOT)
  Westminster Larger Catechism: { Number, Question, Answer, AnswerWithProofs, Proofs }
  Westminster Shorter Catechism: { Number, Question, Answer } (NO proofs in this document)

PROOF_TEXT_FORMAT: Dot-notation with period separators. Book.Chapter.Verse
  Single verse: "Ps.19.1", "Rom.11.36", "1Cor.10.31"
  Range: "Ps.19.1-Ps.19.3", "Rom.1.19-Rom.1.20"
  Range always uses two full Book.Ch.V endpoints (not abbreviated like Gen.1.1-5)
  Dash between digit (end of first verse number) and letter (start of second book abbreviation)
  Books with digit prefix: "1Cor", "2Tim", "1Pet", etc.

  Canon: Zwingli's 67 articles, Canons of Dort, Council of Orange, Tetrapolitan, etc.
